# Autoheater ESP32

Прошивка ESP32 для мониторинга и управления автономным дизельным отопителем через штатную однопроводную полудуплексную шину пульта.

**Текущая версия прошивки: 0.0.1**

## Возможности

- Телеметрия: состояние, шаг программы, температура узла, напряжение, обороты вентилятора и счётчик доз топлива.
- Команды пуска, остановки и изменения мощности по документированному протоколу.
- Оверрайд мощности, если штатный пульт перезаписывает уставку.
- Тихий опрос регистров после остановки обмена со штатным пультом.
- Локальный веб-интерфейс, OTA и OLED 128×64.

## Подключение

Для классической ESP32 DevKit:

| Сигнал | GPIO |
|---|---:|
| UART RX | 16, через делитель 10 кОм / 20 кОм |
| UART TX | 17, только через диод 1N4148 |
| OLED SDA | 21 |
| OLED SCL | 22 |

GND должна быть общей. DATA-шина имеет уровень 5 В: прямое подключение к GPIO ESP32 запрещено. Подробности и ориентация диода приведены в [спецификации протокола](docs/HEATER_PROTOCOL.md).

## Первая установка по USB

Для чистой классической ESP32 DevKit с flash 4 МБ используйте **`factory.bin`** из артефакта GitHub Actions или из GitHub Release. Это полный образ размером 4 МБ: загрузчик, таблица разделов с двумя OTA-слотами, начальные данные OTA и приложение.

1. Скачайте и распакуйте артефакт `autoheater-esp32-firmware`.
2. Установите esptool (в окружении Arduino-ESP32 2.0.9 он уже входит в комплект) либо установите его отдельно.
3. Определите COM-порт платы и выполните:

   ```bash
   python -m esptool --chip esp32 --port COM5 erase_flash
   python -m esptool --chip esp32 --port COM5 --baud 460800 write_flash -z 0x0 factory.bin
   ```

   В Linux вместо `COM5` укажите, например, `/dev/ttyUSB0`.

4. После завершения записи перезапустите плату. Она создаст точку доступа `Autoheater`; веб-интерфейс доступен по адресу `http://192.168.4.1/`.

Для Arduino IDE можно открыть папку `factory/` как отдельный скетч (в ней лежат `factory.ino`, `web_page.h` и `partitions.csv`), выбрать плату `ESP32 Dev Module` и нажать Upload. IDE использует пользовательскую таблицу разделов из папки скетча.

**Важно:** таблица рассчитана на flash 4 МБ. Перед прошивкой проверьте объём flash конкретной платы. Команда `erase_flash` полностью стирает содержимое ESP32. Не используйте `factory.bin` для обычного OTA-обновления.

## Обновление по OTA

Для последующих обновлений используйте только `autoheater-esp32.bin` через ElegantOTA по адресу `http://192.168.4.1/update`. Этот файл содержит только приложение и предназначен для уже установленной разметки с двумя OTA-слотами.

**Перед подключением к отопителю замените тестовые Wi-Fi и OTA-учётные данные в начале `App.ino`.** Проверьте электрическую схему по спецификации. Команды управления и полный цикл пуска/остановки пока требуют проверки на реальном оборудовании.

## Версия и релизы

Единственный источник версии и заметок выпуска — маркеры \`FIRMWARE_VERSION\` и \`CHANGELOG_START / CHANGELOG_END\` в начале \`App.ino\`.

После изменения маркеров выполните:

\`\`\`bash
python3 tools/extract_changelog.py
python3 tools/update_readme_version.py
\`\`\`

Скрипты обновят \`CHANGELOG.md\` и версию в этом README. GitHub Actions проверяет синхронизацию, собирает прошивку и публикует GitHub Release только для тега \`vX.Y.Z\`, совпадающего с версией в App.ino.

## Проверка

Успешная компиляция подтверждает только корректность сборки. Обмен по реальной шине, электрическая совместимость и полный цикл пуска/остановки должны быть проверены на оборудовании отдельно.
