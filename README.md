# Autoheater ESP32

Прошивка ESP32 для мониторинга и дистанционного управления китайским автономным дизельным отопителем через штатную однопроводную полудуплексную шину пульта.

**Единственный актуальный источник сведений о протоколе:** [HEATER_PROTOCOL.md](docs/HEATER_PROTOCOL.md). В нём описаны физический уровень, формат кадров, CRC-8/MAXIM, регистры, состояния отопителя, команды и схема согласования с ESP32.

## Основная прошивка

- firmware/app/app.ino — рабочая прошивка: UART 9600 8N1, разбор кадров A5/A0, CRC-8/MAXIM, телеметрия, команды пуска/остановки/мощности, оверрайд мощности, веб-интерфейс, OLED и OTA.
- firmware/app/app.cpp — версия и changelog для автоматизации релизов; runtime-кода здесь нет.
- firmware/bootstrap/ — начальная прошивка для первичной записи по USB.
- docs/HEATER_PROTOCOL.md — спецификация протокола и чек-лист проверки.

## Подключение

| Сигнал | ESP32 DevKit |
|---|---:|
| UART RX | GPIO16, через делитель 10 кОм / 20 кОм |
| UART TX | GPIO17, через диод 1N4148 |
| OLED SDA | GPIO21 |
| OLED SCL | GPIO22 |
| GND | Общая земля после проверки |

**Не подключайте DATA напрямую к GPIO ESP32.** Линия имеет логический уровень 5 В. RX подключается через делитель, TX — только через диод с ориентацией, указанной в протоколе. Не подключайте TX напрямую к шине.

## Запуск

1. Убедитесь, что электрическая схема собрана строго по разделу 7 протокола.
2. Прошейте начальную прошивку из firmware/bootstrap/, если ESP32 ещё не настроена для OTA.
3. Подключитесь к Wi-Fi Autoheater (пароль стенда 12345678).
4. Откройте http://192.168.4.1/. Обновление прошивки доступно по /update (стендовые учётные данные admin / admin).

Стендовые пароли нельзя использовать в постоянной установке. Замените их до эксплуатации.

## Сборка и выпуск

GitHub Actions собирает основную прошивку и bootstrap для esp32:esp32:esp32 (Arduino ESP32 Core 2.0.9), проверяет наличие бинарников и публикует OTA-артефакты. Правила версионирования и метки PR описаны в docs/release-process.md.

## Статус проверки

Формат протокола и значения регистров описаны по результатам анализа логов в HEATER_PROTOCOL.md. Компиляция подтверждает только корректность сборки. Электрическую схему, передачу команд и полный цикл запуска/остановки необходимо отдельно проверить на реальном оборудовании по чек-листу раздела 9 протокола.
