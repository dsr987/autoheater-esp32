# Autoheater ESP32

Прошивка ESP32 для мониторинга и управления автономным дизельным отопителем через штатную однопроводную полудуплексную шину пульта.

**Текущая версия прошивки: 0.0.2**

## Возможности

- Телеметрия: состояние, шаг программы, температура узла, напряжение, обороты вентилятора и счётчик доз топлива.
- Команды пуска, остановки и изменения мощности по документированному протоколу.
- Оверрайд мощности, если штатный пульт перезаписывает уставку.
- Тихий опрос регистров после остановки обмена со штатным пультом.
- Локальный веб-интерфейс, OTA и OLED 128×64.

## Аппаратное подключение

Для классической ESP32 DevKit:

| Сигнал | GPIO |
|---|---:|
| UART RX | 16, через делитель 10 кОм / 20 кОм |
| UART TX | 17, только через диод 1N4148 |
| OLED SDA | 21 |
| OLED SCL | 22 |

GND должна быть общей. DATA-шина имеет уровень около 5 В: прямое подключение к GPIO ESP32 запрещено. Подробная схема, список компонентов, питание, порядок монтажа и контрольный список находятся в [инструкции по сборке](docs/HARDWARE_ASSEMBLY.md).

## Первая установка по USB

Для новой классической ESP32 DevKit с Flash 4 МБ используй общую заводскую прошивку из отдельного репозитория [ESP32 Factory](https://github.com/dsr987/esp32-factory).

Для Autoheater выбирай **Basic**. Прошивка предназначена для мониторинга и управления отопителем, не содержит тяжёлой графики и не хранит большие локальные журналы, поэтому стандартной разметки достаточно. Basic совпадает с таблицей Arduino ESP32 Core 2.0.9: два OTA-слота по `0x140000` байт каждый. NVS остаётся на стандартном месте и используется библиотекой `Preferences`.

1. Скачай архив `esp32-factory-4mb.zip` из [GitHub Release ESP32 Factory](https://github.com/dsr987/esp32-factory/releases/tag/Release).
2. Запусти `ESP32-Auto-Flasher.bat` и выбери **Factory Reset → Basic**. Эта операция полностью стирает Flash и устанавливает универсальную Factory с нужной таблицей разделов.
3. Подключись к Wi-Fi `ESP32`, пароль `12345678`.
4. Открой `http://192.168.4.1/update`. Логин и пароль ElegantOTA: `admin` / `admin`.
5. Загрузи app-only файл `autoheater-esp32.bin` из артефакта сборки или GitHub Release этого проекта.

После обновления Factory заменится прошивкой Autoheater, а точка доступа станет `Autoheater`.

**Важно:** Factory Reset стирает всё содержимое Flash, включая сохранённые настройки `Preferences`. Для обычных обновлений используй только app-only `autoheater-esp32.bin` через ElegantOTA. Повторно выполнять Factory Reset не нужно.

## Обновление по OTA

Для последующих обновлений используйте только autoheater-esp32.bin через ElegantOTA по адресу http://192.168.4.1/update. Это бинарник приложения без загрузчика и таблицы разделов. Он предназначен для устройства, установленного со стандартной таблицей ESP32 с двумя OTA-слотами.

## Версия и релизы

Единственный источник версии и заметок выпуска — маркеры FIRMWARE_VERSION и CHANGELOG_START / CHANGELOG_END в начале App.ino.

После изменения маркеров выполните:

~~~bash
python3 tools/extract_changelog.py
python3 tools/update_readme_version.py
~~~

Скрипты обновят CHANGELOG.md и версию в этом README. GitHub Actions проверяет синхронизацию, собирает app-only бинарник прошивки и публикует GitHub Release только для тега vX.Y.Z, совпадающего с версией в App.ino. Универсальная Factory собирается отдельно в репозитории [esp32-factory](https://github.com/dsr987/esp32-factory).

## Проверка

Успешная компиляция подтверждает только корректность сборки. Обмен по реальной шине, электрическая совместимость и полный цикл пуска/остановки должны быть проверены на оборудовании отдельно.
