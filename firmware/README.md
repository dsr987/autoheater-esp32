# Прошивка Autoheater ESP32

- app/app.ino — основная прошивка: UART 9600 8N1, протокол кадров A5/A0, CRC-8/MAXIM, телеметрия регистров, команды пуска/остановки/мощности, оверрайд мощности, веб-интерфейс WebSocket, OLED и ElegantOTA.
- app/app.cpp — только версия и changelog для release automation; runtime-кода здесь нет.
- bootstrap/ — начальная прошивка ElegantOTA для первичной записи через USB.

## Каноническая документация

Все сведения о протоколе, регистрах, таймингах и электрическом интерфейсе находятся в ../docs/HEATER_PROTOCOL.md. Не использовать старые заметки о 48-байтовых кадрах, CRC16/Modbus, 25 000 бод или интерфейсе receive-only: они относятся к отвергнутой гипотезе другого устройства.

## Первый запуск

1. Сверьте электрическое подключение с разделом 7 HEATER_PROTOCOL.md. DATA имеет уровень 5 В: GPIO ESP32 не допускают прямого подключения такого сигнала.
2. GitHub Actions собирает OTA-бинарник autoheater-esp32.bin и SHA-256 из firmware/app/.
3. Подключитесь к Wi-Fi точке доступа Autoheater, пароль стенда 12345678.
4. Откройте http://192.168.4.1/; OTA доступно по адресу /update.

Стендовые пароли в исходном коде необходимо заменить перед постоянной эксплуатацией.

Сборка рассчитана на esp32:esp32:esp32, Arduino ESP32 Core 2.0.9. OTA-бинарник предназначен для обновления уже работающей прошивки, не для первичной записи по адресу 0x0.
