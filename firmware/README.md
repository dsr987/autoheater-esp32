# Прошивка ESP32

На текущем этапе готовой прошивки нет: электрический интерфейс и протокол не установлены.

## План реализации

1. `capture` — пассивное чтение подтверждённого интерфейса и сохранение байтов/временных меток.
2. `decode` — разбор кадров на основании подтверждённых правил протокола.
3. `state` — модель состояний пульта и отопителя с явным представлением неизвестных значений.
4. `interface` — вывод проверенных данных в выбранный интерфейс.
5. `control` — возможен только после отдельного исследования команд, электрической совместимости и безопасных условий управления.

## Требования к коду

- Не печатать «декодированные» значения, если алгоритм ещё не подтверждён; помечать сырые данные как raw.
- Не блокировать приём долгими задержками.
- Разделять захват, декодирование и интерфейс.
- Сохранять тестовые захваты и использовать их для регрессионной проверки парсера.
- Не отправлять команды при загрузке, потере связи или неизвестном состоянии.
- Все контакты и электрические требования описывать в комментариях после фактической проверки.
