# Прошивка Autoheater ESP32

- `app/` — основное приложение с локальной веб-панелью; связь с отопителем и WebSocket пока не реализованы.
- `app/app.cpp` — точка входа, настройки точки доступа и учётные данные.
- `app/web_page.cpp` / `app/web_page.h` — HTML-интерфейс и HTTP-сервер.
- `bootstrap/` — стартовая прошивка ElegantOTA для первичной записи через USB.

## Первый запуск приложения

1. Прошить основной бинарник или собрать его через GitHub Actions.
2. Подключиться к Wi-Fi точке доступа `Autoheater`, пароль по умолчанию в `firmware/app/app.cpp`: `heater8260`.
3. Открыть в браузере `http://192.168.4.1/`.
4. При запросе HTTP Basic Authentication использовать логин `admin` и пароль `heater-admin-8260`.

Пароли задаются в начале `app.cpp`. Измените их перед использованием вне тестового стенда. Если изменяете имя точки доступа или пароль, это не влияет на адрес веб-панели.

## Текущее состояние интерфейса

Температуры показывают демонстрационные значения: уличная — около 25 °C, теплообменник — около 85 °C. Значения меняются в браузере каждые две секунды. Переключатель питания и выбор режимов P1–P5 работают только на стороне страницы и не управляют отопителем. WebSocket и протокол пока не подключены.

Сборка рассчитана на `esp32:esp32:esp32`, ESP32 Arduino Core 2.0.9. Не меняйте схему разделов только у одной прошивки без проверки совместимости OTA. Подключение к линиям штатного пульта не реализовано до подтверждения электрических характеристик.

GitHub Actions создаёт `autoheater-esp32.bin` и SHA-256. OTA-бинарник предназначен для обновления уже работающей прошивки, не для первичной записи по адресу 0x0.
