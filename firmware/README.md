# Прошивка Autoheater ESP32

- `app/` — основное приложение; сейчас это безопасный Hello World-каркас.
- `bootstrap/` — стартовая прошивка ElegantOTA для первичной записи через USB.

Сборка рассчитана на `esp32:esp32:esp32`, ESP32 Arduino Core 2.0.9. Не меняйте схему разделов только у одной прошивки без проверки совместимости OTA. Подключение к линиям штатного пульта не реализовано до подтверждения электрических характеристик.

Сборка GitHub Actions создаёт `autoheater-esp32.bin` и SHA-256. OTA-бинарник предназначен для обновления уже работающей прошивки, не для первичной записи по адресу 0x0.
