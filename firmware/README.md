# Прошивка Autoheater ESP32

- `app/app.ino` — основная прошивка: пассивный приём BM, веб-панель, журнал LittleFS, скачивание TXT, очистка журнала и OTA.
- `app/app.cpp` — метаданные версии и changelog для автоматизации релизов; runtime-кода здесь нет.
- `wiretap_line_bm/` — историческая копия эксперимента; основной workflow её больше не собирает.
- `bootstrap/` — стартовая прошивка ElegantOTA для первичной записи через USB.

## Первый запуск

1. GitHub Actions собирает OTA-бинарник `autoheater-esp32.bin` и SHA-256 из `firmware/app/`.
2. Подключитесь к Wi-Fi точке доступа `Autoheater`, пароль `12345678`.
3. Откройте `http://192.168.4.1/`; журнал доступен на странице, обновление — по адресу `/update`.

Пароли в текущей прошивке предназначены только для стенда. Измените их перед использованием вне лаборатории.

Протокол BM остаётся экспериментальным: команды в BM не передаются, корректность декодирования телеметрии не подтверждена. ESP32 нельзя подключать напрямую к сигналу выше 3,3 В без подходящей защиты/согласования уровней.

Сборка рассчитана на `esp32:esp32:esp32`, ESP32 Arduino Core 2.0.9. OTA-бинарник предназначен для обновления уже работающей прошивки, не для первичной записи по адресу 0x0.
