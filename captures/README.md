# Захваты протокола

Каталог предназначен для исходных файлов логического анализатора, осциллограмм и их описаний. Пока реальные дампы не добавлены.

## Правила хранения

- Не редактировать исходный файл захвата; производные данные хранить отдельно.
- На каждый захват создавать одноимённый файл описания `.md`.
- Имя файла: `YYYY-MM-DD_device_action_takeNN.ext`, например `2026-10-18_panel_idle_take01.sal`.
- Не включать в репозиторий секреты или персональные данные.
- Перед загрузкой проверить, что захват не содержит случайно записанных чувствительных данных.

## Обязательные метаданные

- Дата и время.
- Модель отопителя и пульта либо пометка «не установлено».
- Точка подключения и схема подключения.
- Прибор и версия ПО.
- Частота дискретизации, диапазон входа и параметры декодирования.
- Состояние отопителя и пульта до захвата.
- Ровно какое действие выполнялось и в какой момент.
- Имя исходного файла и контрольная сумма при возможности.
- Первичное наблюдение без преждевременной интерпретации.

Не добавлять выдуманные дампы или синтетические данные под видом измерений.
