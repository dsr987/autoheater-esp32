# Архив: ранняя гипотеза BM wiretap

Этот документ относится к прежней прошивке пассивного сниффера с кадрами 48 байт и CRC16/Modbus. Та гипотеза отвергнута после анализа протокола конкретного пульта.

**Не использовать** приведённые здесь распиновку, скорость 25 000 бод, формат кадров или инструкции по receive-only режиму для текущей прошивки.

Актуальные сведения: HEATER_PROTOCOL.md.
