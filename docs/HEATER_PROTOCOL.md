# Протокол связи пульта и печки (китайская автономка, дизель)

Реверс по логам логического анализатора (Saleae Logic 2, экспорт CSV).
Статус: физический уровень и формат кадра подтверждены, CRC подтверждена,
семантика большей части регистров — рабочие гипотезы по динамике.

## Физический уровень

- 3 провода: красный +5 В (питание), синий — данные, чёрный — GND.
- Полудуплексный UART по одному проводу: TX и RX обоих устройств на одной линии,
  обмен поочерёдный. Логика 5 В, лог. 1 — высокий уровень.
- **9600 бод, 8N1** (подтверждено: длительность бита ~104 мкс, межбайтовая пауза
  1,03 мс = 10 битовых интервалов, ноль ошибок кадрирования, CRC сходится).
- Мастер — пульт, слейв — блок печки.
- Реплика (цикл опроса) ~1,14 с: пульт пишет мощность, шлёт 2 телеметрии,
  затем опрашивает 8 регистров; ответ слейва через ~14 мс после каждого запроса.

## Формат кадра

    [SYNC][CMD][LEN_HI][LEN_LO][DATA × LEN][CRC8]

- SYNC: `0xA5` — мастер (пульт), `0xA0` — слейв (печка)
- CMD: `0x30` — чтение регистра (мастер), `0x01` — запись (мастер),
  `0x20` — телеметрия мастера (без ответа), `0x00` — ответ слейва
- LEN: длина DATA, 16 бит big-endian (`00 01`, `00 04`, `00 05`)
- CRC8: **CRC-8/MAXIM** — полином 0x31 (LSB-first реализация 0x8C), init 0x00,
  xorout 0x00 (семейство Dallas 1-Wire). Считается по всем байтам от SYNC до
  конца DATA включительно. CRC в кадре не входит.
- Заголовок = 4 байта (SYNC+CMD+LEN16). ВНИМАНИЕ: в ранней версии разбора
  ошибочно считался 5-байтовый заголовок — из-за этого часть кадров терялась.

Статистика валидации: лог 1 — 358/360 кадров; лог 2 — 1897 кадров, 99,5 % байт;
лог 3 — 51/51; лог 4 — без ошибок. Одиночный сбой бита (LEN 0x01→0x21) печка
корректно расшифровала и ответила — протокол живуч к одиночным ошибкам.

## Команды

| CMD | Кто | Смысл |
|-----|-----|-------|
| 0x30 | мастер | чтение регистра: DATA = [адрес (1 байт)] |
| 0x01 | мастер | запись: DATA = [адрес][float32 LE], LEN = 0x0005 |
| 0x20 | мастер | телеметрия: DATA = [00]=темп. с пульта float, [01]=второй параметр (всегда 0.0 — вероятно, внешний датчик не подключён) |
| 0x00 | слейв | ответ на чтение: DATA = значение регистра |

Команды пишутся троекратно подряд (интервал ~21 мс) — дублирование для надёжности.

## Регистры

### Запись (мастер → печка)

| Рег | Тип | Значение | Примечание |
|-----|-----|----------|------------|
| 0x01 | float | мощность, Вт | 1000 → 1900 → 2800 → 3700 → 4600 = ступени 1–5 кВт |
| 0x03 | float | 1.0 = старт, 0.0 = стоп | подтверждено по логам пуска и остановки |
| 0x02 | float | 0.0 ×3 при старте | неизвестно (возможно, сброс/подготовка) |
| 0x05 | float | 0.0219 | неизвестно |

### Чтение (печка → мастер)

| Рег | Тип | Наблюдения | Гипотеза | Уверенность |
|-----|-----|------------|----------|-------------|
| 0x0B | u8 | всегда 0xFF | код ошибки (0xFF = нет ошибки) | средняя |
| 0x0C | u32 | 1 (при подаче питания), 2→4→5→6→7→13 | номер шага программы горения (синхронен с 0x50) | высокая |
| 0x50 | u8 | 0x20 → 0x24 → 0x25 → 0x27 → 0x2E | машина состояний (см. ниже) | высокая |
| 0x20 | float | 50,7→38,4 °C (остывание), 167 °C и 192 °C (горение), растёт при работе | температура узла печки (теплообменник/камера), вероятно канал защиты от перегрева | высокая |
| 0x23 | u32/f32 | всегда 0 | неизвестно (второй датчик?) | низкая |
| 0x24 | float | 13,02–13,79 В, проседает под нагрузкой | напряжение питания | высокая |
| 0x10 | u32 | 31651/31657/32994… тикает +2…+3 за цикл опроса, заморожен на прогреве/розжиге | счётчик доз топлива (впрысков насоса); персистентный между сессиями | средняя |
| 0x16 | u32 | 0; 716 (разгон); 1500–2840 на мощности 1; растёт с мощностью | обороты вентилятора, об/мин | высокая |
| 0x03 | float | 4600.0 при опросе после подачи питания | последняя сохранённая мощность? конфликтует с записью старт/стоп — уточнить | низкая |
| 0x04 | float | 1000.0 | неизвестно (мин. мощность / заводское значение?) | низкая |
| 0x66 | u32 | 0 | неизвестно | низкая |

Пул опроса в рабочих циклах: 0x0B, 0x0C, 0x50, 0x20, 0x23, 0x24, 0x10, 0x16.
При подаче питания пульт дополнительно опрашивает: 0x01 (мусор FF 02 47 CB),
0x05, 0x0B, 0x03, 0x04, 0x0C, 0x10, 0x66.

## Машина состояний (0x50) и шаги (0x0C) — лог пуска

| Время, с | Событие |
|----------|---------|
| 0,73–1,35 | опрос настроек после подачи питания |
| 1,42 | запись 0x02 = 0 ×3 |
| 1,55 | запись 0x03 = 1 (старт) |
| 2,89 | 0x50 → 0x20, шаг 2 — прогрев (свеча) |
| 4,57 | вентилятор 0 → 716 об/мин |
| 5,06 | 0x50 → 0x24, шаг 4 — розжиг (насос + свеча), ~14 с |
| 9,38 | шаг → 4 |
| 19,56 | 0x50 → 0x25 — пламя поймано, горение |
| 20,6 → 49,7 → 110,2 | шаги 5 → 6 → 7 |
| 110,32 | 0x50 → 0x27 — переход БЕЗ команды с пульта |
| 112,45 | запись 0x03 = 0 ×3 (стоп) |

Установившееся горение: **0x2E / шаг 13** (подтверждено двумя логами).
Переход 0x27 при штатной остановке наступил за 2,2 с до команды стоп.

## Наблюдения и открытые вопросы

1. Темп тикания 0x10 зависит от режима: ~2,7/с при 192 °C, ~1,75/с при 167 °C
   (мощность 1). Проверка: гонять мощность 1→5 — темп должен расти.
2. Обороты вентилятора (0x16) на одной мощности 1 менялись между логами
   (1500 / 2400 / 2800) — зависят не только от уставки, но и от фазы/температуры.
3. Не снята фаза остановки: продувка, коды 0x50 при shutdown, остывание 0x20,
   выбег вентилятора. Все логи после стопа обрывались через <10 с (проверять
   настройки экспорта Logic 2 — «entire capture»).
4. Неизвестны: назначение записей 0x02 и 0x05, регистры 0x04, 0x23, 0x66,
   конфликт 0x03 (запись = старт/стоп, чтение = 4600.0).
5. Коды состояний между 0x25 и 0x2E (0x27) и при остановке — не полные.

## Инструменты

- `decode_heater.py` — парсер CSV лог-анализатора: нарезка кадров по паузам,
  валидация CRC-8/MAXIM, декодирование регистров в человекочитаемый вид.
  Запуск: `python3 decode_heater.py "лог.csv"`

## Хронология логов

- Лог 1 (`async serial 9600.csv`): установившееся горение, ступени мощности
  1000→4600, U 13,68–13,73 В, вентилятор 2400→2680, узел 177,8→175,9 °C.
- Лог 2 (пуск): полный цикл старта, см. таблицу выше.
- Лог 3 (работа на 1, стоп): обрезан (3,5 с), пойман момент стопа
  (0x03=0 ×3 на 2,66 с), горение 0x2E/шаг 13, узел 192 °C, U 13,68–13,70 В.
- Лог 4 (работа на 1, стоп 2): обрезан (9,2 с), стоп на 8,41 с. Битый кадр
  (LEN 0x01→0x21) — печка ответила верно. 0x10: +2/цикл при 167 °C.
