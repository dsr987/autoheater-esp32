# История исследования протокола

Актуальная спецификация и подтверждённые результаты анализа перенесены в HEATER_PROTOCOL.md.

Этот файл больше не является инструкцией по текущему протоколу. Ранние записи о неизвестном типе интерфейса, поиске UART-скорости, пассивном приёме и неопределённых регистрах относятся к начальному этапу исследования и не должны использоваться при разработке прошивки.

Для текущих экспериментов и проверки реализации использовать только:
- HEATER_PROTOCOL.md — физический уровень, кадры, CRC, регистры, тайминги и чек-лист;
- hardware-notes.md — актуальная распиновка и электробезопасность.
