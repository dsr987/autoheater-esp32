# Архив: диагностический UART baud sweep

Этот эксперимент относился к прежнему пассивному снифферу, который искал кадры 48 байт с CRC16/Modbus на нескольких скоростях. Он не относится к текущему протоколу.

Текущая скорость подтверждена анализом временных интервалов: 9600 бод, 8N1. Формат кадров и CRC описаны в HEATER_PROTOCOL.md.

Не использовать старую процедуру перебора скоростей и старые проверки заголовков.
